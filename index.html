RUANG UNTUK CERITA KALIAN

Bikin semakin kamu.

Website ini sudah siap menjadi rumah untuk momen kalian. Masukkan file lewat VS Code, lalu simpan.

  1. Salin foto ke folder public/media/photos/.
  2. Buka public/config.js, lalu isi src pada bagian photos.
src: '/media/photos/kita.jpg'

JPG, PNG, atau WebP. Disarankan di bawah 2 MB per foto. Jangan lupa ubah caption dan alt sesuai momen kalian.

  1. Salin video ke public/media/video/.
  2. Isi bagian video di public/config.js.
src: '/media/video/kita.mp4'

Gunakan MP4 (H.264 + AAC), usahakan di bawah 50 MB untuk Vercel. Video tidak diputar otomatis.

Semua nama, alasan sayang, surat, harapan, dan kupon ada di satu file:

public/config.js

Ubah recipient menjadi nama pasanganmu, dan sender menjadi namamu. Tulisan surat bisa kamu ganti seluruhnya.

Panduan lengkap dan cara publish ke Vercel ada di README.md. Semua pratinjau lokal hanya ada di browser kamu.

Tidak ada file yang dikirim ke server. Kenanganmu tetap milikmu.
