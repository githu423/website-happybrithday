UNTUKMU. — CARA MENCOBA DI VS CODE
=================================

Tidak perlu deploy ke Vercel dulu. Semua bisa dites di komputer sendiri.

1. PASANG NODE.JS
   Pasang Node.js versi 22 LTS (minimal 22.12) dari https://nodejs.org/.
   Versi 20.19+ juga didukung. Jika baru selesai install, tutup lalu buka lagi VS Code.
   Cek di Terminal VS Code:
     node --version
     npm --version

2. AMBIL PROYEK DARI GITHUB
   Pasang Git jika belum ada, lalu di Terminal VS Code jalankan:

     git clone --branch arena/e478c91e-website-happybrithday --single-branch https://github.com/githu423/website-happybrithday.git
     cd website-happybrithday
     code .

   Jika folder proyek sudah ada dari clone sebelumnya:
     cd website-happybrithday
     git pull origin arena/e478c91e-website-happybrithday

   Di VS Code: File > Open Folder, pilih folder yang berisi package.json.
   Jangan hanya membuka file index.html satu per satu.

3. JALANKAN WEBSITE
   Buka Terminal > New Terminal, lalu ketik:

     npm install
     npm run dev

   Tunggu sampai muncul alamat lokal. Buka:
     http://localhost:3000

   Biarkan terminal tetap berjalan selama mencoba website.
   Untuk berhenti: tekan Ctrl+C di terminal.

   PENTING: Jangan buka index.html dengan klik dua kali atau Live Server biasa.
   Proyek ini memakai Vite, jadi jalankan npm run dev.

   CARA MEMBUKA HADIAH
   Website sekarang berbentuk buku kejutan seperti hadiah Hari Girlfriend:
     1. Sampul: jawab “Iya, aku”. Tombol “Bukan” akan kabur.
     2. Pembuka: ketuk amplop.
     3. Ucapan: baca surat yang muncul.
     4. Waktu Kita: lihat hitungan hari hubungan.
     5. Eren: ajak maskot main minimal 3 kali.
     6. Mawar: petik minimal 3 mawar.
     7. Album: buka satu foto.
     8. Kuis: jawab semua pertanyaan.
     9. Isi Hati: tahan hati sampai 100%, atau klik “Lewati animasi tahan”.
     10. Video: tonton video kalian.
     11. Sertifikat: tanda tangan, lalu download PNG.
     12. Penutup: kirim sayang atau ulang dari awal.

   Beberapa halaman mengunci tombol Lanjut sampai tugasnya selesai.
   Progres tersimpan di browser. Refresh tidak mengulang dari awal.

4. MASUKKAN ISI PERSONAL
   Nama, surat, mawar, kuis, sertifikat, dan penutup:
     public/config.js

   Foto kalian:
     public/media/photos/
   Video kalian:
     public/media/video/
   Musik sendiri (opsional):
     public/media/music/
   Tanda tangan kamu (opsional):
     public/media/signature.png

   Setelah menyalin file media, daftarkan path-nya di public/config.js.
   Contoh path foto: /media/photos/kita.jpg
   Contoh path video: /media/video/kita.mp4
   Jangan menulis /public di depan path tersebut.
   Nama file dan huruf besar/kecil harus sama persis.

   Simpan perubahan dengan Ctrl+S. Browser biasanya memperbarui otomatis;
   jika belum, refresh browser.
   Tombol Coba Foto Kamu / Coba Video Lokal hanya pratinjau sementara,
   bukan upload dan bukan cara menyimpan file ke proyek.

5. TES SEBELUM PUBLISH (OPSIONAL)
   Cek konfigurasi dan file media:
     npm test

   Cek versi produksi berhasil dibuat:
     npm run build

   Lihat hasil build di browser:
     npm run preview

   Tes interaksi lengkap dengan browser (opsional):
     npx playwright install chromium
     npm run test:e2e

6. KALAU TERMINAL WINDOWS MENOLAK NPM
   Jika muncul error execution policy untuk npm.ps1 di PowerShell,
   pilih Terminal Command Prompt di VS Code, atau gunakan:
     npm.cmd install
     npm.cmd run dev
   Tidak perlu mematikan keamanan PowerShell.

7. KALAU ADA MASALAH
   - npm not found: install Node.js, lalu buka ulang VS Code.
   - Cannot find package.json: buka folder website-happybrithday hasil clone.
   - git pull gagal: pastikan clone branch yang tertulis di langkah 2.
     Jangan paksa reset jika ada perubahan pribadi yang belum disimpan.
   - Port sudah dipakai: gunakan alamat lain yang muncul di terminal.
   - Foto/video tidak tampil: cek path dan nama file di config.js.
   - Video tidak dapat diputar: gunakan MP4 dengan H.264 + AAC.
   - Ingin mengulang dari awal: buka halaman Penutup, klik “Ulang dari awal”.
